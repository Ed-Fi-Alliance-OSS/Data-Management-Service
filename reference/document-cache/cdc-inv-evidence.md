# DocumentCache CDC-INV Evidence Matrix

This matrix records the current DMS-1317 evidence inventory for the completed E18
DocumentCache capability. It is intentionally evidence-oriented: each row names the
implemented tests that already prove part of the contract and the remaining DMS-1317 gap
when the contract still needs cross-story evidence.

## Scope

In scope for DMS-1317:

- `CDC-INV-01`: configuration, target selection, durable lifecycle, and projection status.
- `CDC-INV-02`: cached document contract.
- `CDC-INV-03`: transactional enqueue, freshness, acknowledgement, concurrency, and
  performance qualification.
- `CDC-INV-04`: bounded projector execution, baseline, rebuild, restart, and no-scan
  status.
- `CDC-INV-05`: cache-backed reads, fallback, authorization, direct fill, and concurrency.
- `CDC-INV-14`: repair, rebuild, scrub, cache-ahead recovery, and exercised runbooks.
- `CDC-INV-15`: security, telemetry, operations, no-scan status, and exercised runbooks.

Out of scope for DMS-1317 implementation except for runbook cross-links:

- `CDC-INV-06` through `CDC-INV-13` are E19-owned Kafka connector, topic, source-position,
  binding, public consumer bootstrap, pinned connector runtime, and downstream CDC
  readiness contracts.
- Restamp implementation and primary restamp tests are owned by DMS-1318. Until DMS-1318
  lands, restamp remains a conditional DMS-1317 evidence row rather than executable
  coverage.
