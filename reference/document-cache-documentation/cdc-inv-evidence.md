# DocumentCache CDC-INV Evidence Matrix

This matrix is the traceability record for the durable DocumentCache projection boundary.
Each in-scope row identifies provider-specific evidence, shared or existing evidence,
DocumentCache projection evidence, and an explicit exclusion or deferred-evidence note.
The paths are repository-relative so the matrix can be checked without provider databases.

## Scope and ownership

The in-scope DocumentCache evidence covers `CDC-INV-01` through `CDC-INV-05`, plus
`CDC-INV-14` and `CDC-INV-15`:

- `CDC-INV-01`: configuration, target selection, durable lifecycle, and projection status.
- `CDC-INV-02`: cached document contract and provider-equivalent materialization.
- `CDC-INV-03`: transactional enqueue, freshness, acknowledgement, concurrency, and write
  overhead.
- `CDC-INV-04`: bounded projector execution, baseline, rebuild, restart, and no-scan status.
- `CDC-INV-05`: cache-backed reads, fallback, authorization, direct fill, and concurrency.
- `CDC-INV-14`: repair, rebuild, scrub, cache-ahead recovery, and operational workflows.
- `CDC-INV-15`: security, telemetry, operations, bounded diagnostics, and no-scan status.

`CDC-INV-06` through `CDC-INV-13` are Kafka/CDC connector contracts
(connector topology, topics and records, transformation, pinned runtime, source position,
deployment binding, consumer bootstrap, and retention). This matrix links to Kafka/CDC
operational guidance where an operator workflow crosses the projection boundary, but does
not claim connector implementation or Kafka end-to-end evidence.

Representation restamp implementation, integration coverage, and operator guidance belong
to the independently owned offline byte-changing representation correction workflow. They
are outside the DocumentCache projection boundary and are not prerequisites for this
evidence set.

## Evidence reading notes

- Provider integration tests require their configured PostgreSQL or SQL Server test target;
  the matrix records test identity and path but does not imply that a documentation check
  starts either database.
- `DocumentCacheWriterPerformanceEvidence_it_compares_projector_and_direct_fill_workload_modes`
  is bounded DocumentCache writer component evidence. It is not representative
  qualification evidence, threshold evidence, release-validation evidence, or evidence of
  production-scale performance qualification.
