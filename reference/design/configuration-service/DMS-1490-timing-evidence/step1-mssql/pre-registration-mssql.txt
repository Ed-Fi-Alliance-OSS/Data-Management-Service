Sample plan (fixed now):
- one run; warm-up 1,200 rounds (discarded, kept in their own file); measured N = 2,000 rounds;
- each round sends one request per arm (absent, wrong_secret, unapproved_correct_secret) in an order
  shuffled by System.Random(seed); seed 501 (not used by any earlier run);
- why N = 2,000: the A5 pilot's planning heuristic needed 500 rounds; 2,000 gives a predicted 95%
  half-width of about 19 us against the 125 us target, and dilutes a settling segment like the
  ~125-round slow start seen in the A5 SQL Server final, which 500 rounds could not.

Decision rule (fixed now), primary comparison median(absent) - median(wrong_secret), delta = 250 us,
analyze_timing.py method v1 (95% percentile moving-block bootstrap, L = ceil(N^(1/3)) = 13, 5,000
resamples, seed 1), with diagnostics.py for the 2L interval, flags and half differences:
- EQUIVALENT only if ALL hold: the CI at L lies inside [-250, +250]; the CI at 2L lies inside it;
  diagnostics.py raises no flag (exit 0); and the absent - wrong_secret difference in each half of
  the run lies inside [-250, +250];
- NOT EQUIVALENT if the CI at L is disjoint from [-250, +250];
- otherwise INCONCLUSIVE, which is not a pass and is reported as such.
Secondary, descriptive only: unapproved_correct_secret - wrong_secret, same method.

Conduct:
- a run that produces a complete measured file is final: it is analysed and reported whatever it
  shows, and it is not repeated;
- a setup failure before the collector writes its measured file is not a result: it is recorded
  here and the setup may be corrected and started again;
- every file the collector writes (samples, warm-up, header) is kept unmodified; no round is trimmed;
- the power line status is read before and after the run and reported (no other host monitoring).
