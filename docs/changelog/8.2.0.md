# Changelog: 8.2.0

## Breaking changes

- **DMS no longer ships a fixed cache duration for its Configuration Service token.**
  `CacheSettings:TokenCacheExpirationSeconds` is deprecated throughout 8.x and will be removed
  in the next major release. An explicit positive whole number still caps reuse when shorter
  than the issuer-derived window. A blank, zero, negative or malformed value now fails startup;
  remove the setting to follow the issuer's lifetime. The provided Compose manifests no longer
  map `DMS_TOKEN_CACHE_EXPIRATION_SECONDS`. Older manifests still inject a 1,500-second cap
  even when that variable is unset, so an image-only upgrade retains the cap and emits a
  deprecation warning. See [migration guidance](../CONFIGURATION.md#tokencacheexpirationseconds-deprecated).

## New features

- **The DMS and Configuration Service images now run natively on arm64 hosts.**
  `edfialliance/ed-fi-api` and `edfialliance/ed-fi-api-configuration-service` are published for
  `linux/amd64` and `linux/arm64`, so Apple silicon, AWS Graviton and Azure Cobalt hosts pull
  and run them without emulation. Pulls on amd64 hosts and tag names are unchanged. Each
  release tag carries the same digest as the prerelease image it promotes. Earlier releases,
  such as 8.1.0 and 8.0.0, remain amd64-only; on an arm64 host, pull them with
  `--platform linux/amd64`. See [DMS-1291](https://edfi.atlassian.net/browse/DMS-1291).

## Improvements

- **DMS reuses its Configuration Service token for the lifetime returned by the issuer, less
  a refresh margin of 60 seconds or 10%, whichever is smaller.** Set the lifetime with CMS
  `IdentitySettings:TokenExpirationMinutes` or Keycloak's **Access Token Lifespan**. Missing or
  non-positive lifetime metadata uses a 300-second fallback and logs a warning. Failed grants
  preserve their HTTP status and suppress new grants for five seconds, or 30 seconds after a
  429. A protected read rejected with 401 obtains a replacement and retries once. See
  [DMS-1580](https://edfi.atlassian.net/browse/DMS-1580) and
  [token caching](../CACHING-STRATEGY.md#4-configuration-service-token-cache).
